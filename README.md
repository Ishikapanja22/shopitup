# ShopItUp — E-Commerce Platform

A full-stack MERN e-commerce web app with product browsing, cart management, and secure user authentication.

## Live Demo
(https://shopitup.vercel.app)

## Preview
ShopItUp Preview (./shopitup%20preview.png)

## Features
- User Registration & Login (JWT Auth)
- Add to Cart / Remove from Cart
- Product Listings with Categories
- Order placement flow
- Responsive UI

## Tech Stack
- Frontend : React + Vite 
- Backend : Node.js + Express
- Database : MongoDB

## 🚀 Getting Started

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
